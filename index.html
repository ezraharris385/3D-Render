🌍 Earth

Google photorealistic 3D

Photorealistic 3D

This tab streams Google's Photorealistic 3D Tiles — the same photogrammetry you see in Google Earth — around your placed projects. It needs your own (free-tier) Google key once:

1. Go to console.cloud.google.com → create a project.
2. Search “Map Tiles API” → Enable it.
3. APIs & Services → Credentials → Create credentials → API key.
4. Paste the key here — it stays in your browser only.
